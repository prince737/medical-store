# 🚀 Getting Started

Follow these steps to set up and run the React app locally.

## 📦 Prerequisites

- **Node.js** 
- **npm** 

[Can be downloaded from here](https://nodejs.org/en/download)

After downloading check installation by opening a bash or powershell window
```bash
node -v
npm -v
```

## 🛠 Installation

1. **Clone or download the repository**


```bash
# cloning
git clone https://github.com/prince737/medical-store.git
cd your-project
```

or

[Download in zip format and extract](https://github.com/prince737/medical-store/archive/refs/heads/main.zip)


2. **Install dependencies**

Navigate into medical store directory and open a new powershell or bash window in that folder.

``` bash
npm install
```

3. **run json server**

```bash
npm run start-db
```

4. **start the react app**


```bash
#in a new terminal tab
npm start 
```
